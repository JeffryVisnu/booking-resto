# Tableau Gusteau

## About
Tableau Gusteau yang merupakan Sistem Reservasi Restoran “Gusteau’s” Berbasis Web yang dirancang untuk mendeskripsikan antarmuka sistem, fungsi, dan fitur utama, antara lain pemesanan meja, pengelolaan kapasitas yang dirancang dalam hal memfasilitasi pelanggan untuk reservasi tempat di restoran dan membantu pegawai restoran dalam mengizinkan reservasi. Program ini dibuat untuk memenuhi kebutuhan tugas besar mata kuliah Implementasi dan Perancangan Perangkat Lunak

## Fitur
- Reservasi Restoran
- Melihat Menu
- Notifikasi email reservasi
- Page admin untuk melihat data reservasi
